NHC 개인정보처리방침

시행일: 2026년 10월 26일

1. 목적

NHC는 운영자 본인이 소유한 유튜브·인스타그램·페이스북·스레드 계정에 운영자가 직접 만든 정보 콘텐츠를 게시하기 위한 개인용 도구입니다.

2. 처리하는 정보

운영자 본인 계정의 연결 정보(접근 토큰)만 사용하며, 이는 운영자의 비공개 저장소 보안 금고에만 보관됩니다. 다른 이용자의 개인정보는 수집·저장·제3자 제공하지 않습니다.

3. 구글 사용자 데이터

YouTube Data API는 운영자 채널에 영상을 업로드하는 용도로만 사용합니다. Google API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수하여 사용합니다.

4. 보관 및 삭제

연결은 운영자가 각 서비스의 계정 설정에서 언제든 해제할 수 있으며, 해제 시 토큰은 즉시 폐기됩니다.
